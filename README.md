# Comunidade NR-01

Crie uma plataforma web independente chamada “Comunidade NR-01” com experiência visual e de uso inspirada em uma rede social de posts curtos em tempo real, com feed, comentários, curtidas, reposts e perfis de usuários.

Essa plataforma é um produto separado, não uma área dentro de outro sistema.

O texto de toda a interface deve estar em Português (Brasil).

A aplicação não precisa de backend real. Use apenas dados mockados, estados locais e conteúdo de demonstração. O objetivo é entregar uma comunidade bonita, funcional e convincente, com aparência de produto real.

OBJETIVO DA PLATAFORMA

Criar um espaço de comunidade profissional onde líderes, RH, SST e colaboradores possam trocar experiências, compartilhar boas práticas, discutir temas de saúde emocional no trabalho, liderança, clima organizacional, prevenção de riscos psicossociais e boas práticas ligadas à NR-01.

DIREÇÃO VISUAL

Quero um visual premium, moderno e muito bem acabado, com:

- layout estilo rede social moderna

- feed central

- coluna lateral com atalhos e tendências

- cards elegantes e limpos

- tipografia forte

- espaçamento bem distribuído

- sombras suaves

- cantos arredondados

- animações sutis

- modo claro e escuro

- responsivo para desktop, tablet e celular

A interface deve parecer uma rede social corporativa de alto nível, não um painel genérico.
